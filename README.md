# Resume-skill-gap-analyzer
AI-based Resume Screening and Skill Gap Analyzer


Our project is a Resume Screening and Skill Gap Analyzer.
The system allows a user to upload a resume in PDF format and select a target job role.
We extract text from the resume using a PDF parser, then apply NLP techniques to detect skills mentioned in the resume.
These skills are compared with a predefined dataset of required job skills.
The system calculates a skill match score and identifies missing skills that the candidate should learn.
The results are displayed in a Streamlit web interface, making the tool interactive and easy to use.
